# 台指競技場 手機版（PWA）v1.0.0-m1

## 怎麼試玩（電腦＋手機同一個 Wi-Fi）
1. 解壓 `台指競技場手機版_原始碼.zip`。
2. 雙擊 `啟動手機版測試.bat`（需要電腦有 Python 3；畫面會印出網址，例如 http://192.168.1.23:8800/）。
3. 手機瀏覽器打開那個網址就能玩。這樣測試時「加到主畫面、離線玩」不會啟用（要放上 https 網站才會）。

## 和電腦版的差別
- 沒有本機伺服器：參賽者、每一局、日誌存在手機瀏覽器（IndexedDB）。設定頁可以「匯出備份檔／從備份還原」。
- 撮合、統計、猴子對照的程式完全沿用電腦版。
- 行情檔改成壓縮格式 .arz（317 MB → 30 MB），玩到哪一盤才下載，下載過的留在手機。
- 下單改成觸控：K 線固定在上方，下單按鈕、部位、委託、交易往下滑；限價／停損按了再點圖選價位；委託線可以用手指拖曳改價。
- 沒有 TKS／群益買賣價校準，用內建的價差表。

## 每天更新行情
- `tools/update.py`：用電腦版原本的期交所下載＋匯入程式，抓新交易日、轉成 .arz、更新 `web/data/catalog.json`。
- `.github/workflows/pages.yml`：放上 GitHub 後自動發布網站，每個交易日台北時間 19:30 抓新行情再發布。
- 手機打開 App（之後每 30 分鐘）會檢查目錄，有新的盤就提示。

## 還沒做
- 放上正式網站（GitHub Pages 或 Cloudflare Pages），才會有 https、加到主畫面、離線和自動更新。
- 說明書（manual）還是電腦版的截圖。
